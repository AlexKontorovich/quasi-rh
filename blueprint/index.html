1 · The field K

Let \(\omega\) be a primitive cube root of unity. We work in the quadratic number field

\[K=\mathbb Q(\omega)=\mathbb Q(\sqrt{-3}),\qquad \omega^2+\omega+1=0.\]

Lean uses the third cyclotomic field as its model of \(K\). A single complex embedding is fixed throughout.

¶source embedding source
abbrev K := CyclotomicField 3 ℚ

noncomputable def complexEmbedding : K →+* ℂ := Classical.choice inferInstance

2 · The ring of integers

The ring \(\mathcal O=\mathcal O_K=\mathbb Z[\omega]\) consists of the Eisenstein integers \(a+b\omega\), with \(a,b\in\mathbb Z\). Under the fixed complex embedding it is a triangular lattice.

Lean takes the full ring of integers of \(K\), and obtains \(\omega\) as an algebraic integer. Rows will be elements of this ring; columns will be its integral ideals.

¶source embedding source
abbrev 𝒪 := NumberField.RingOfIntegers K

noncomputable def omega : 𝒪 :=
  (IsCyclotomicExtension.zeta_spec 3 ℚ K).toInteger

noncomputable def toComplex : 𝒪 →+* ℂ :=
  complexEmbedding.comp (algebraMap 𝒪 K)

3 · Ideal and element norms

For a nonzero integral ideal \(\mathfrak n\), its absolute norm is the finite index

\[\mathrm N\mathfrak n=\#(\mathcal O/\mathfrak n).\]

In Lean we use mathlib’s Ideal.absNorm directly. Its underlying function Submodule.cardQuot is the cardinality of the quotient, as recorded by Submodule.cardQuot_apply.

For an element \(u=a+b\omega\), its norm is

\[\mathrm N(u)=u\overline u=|u|^2=a^2-ab+b^2.\]

These conventions agree: \(\mathrm N((u))=\mathrm N(u)\). In particular \(\mathrm N(0)=0\). The Lean element norm is defined through the principal ideal and proved equal to the squared complex absolute value. The coordinate description \(a+b\omega\) remains to be connected explicitly to the abstract model.

¶source

Mathlib definition: Ideal.absNorm

noncomputable def Ideal.absNorm [IsDedekindDomain S] [Module.Free ℤ S] :
    Ideal S →*₀ ℕ where
  toFun := Submodule.cardQuot
  map_mul' I J := by rw [cardQuot_mul]
  map_one' := by rw [Ideal.one_eq_top, cardQuot_top]
  map_zero' := by
    have : Infinite S := Module.Free.infinite ℤ S
    rw [Ideal.zero_eq_bot, cardQuot_bot]

Project element-norm convention and compatibility lemmas:

noncomputable def elementNorm (u : 𝒪) : ℕ := Ideal.absNorm (Ideal.span {u})

theorem elementNorm_eq (u : 𝒪) : elementNorm u = (Algebra.norm ℤ u).natAbs :=
  Ideal.absNorm_span_singleton u

4 · The ideal Möbius function

Factor a nonzero integral ideal uniquely as \(\mathfrak n=\prod_{j=1}^r\mathfrak p_j^{e_j}\), with distinct prime ideals. Define

\[\mu_K(\mathfrak n)=\begin{cases}(-1)^r&\text{if every }e_j=1,\\0&\text{if some }e_j\ge2.\end{cases}\]

The unit ideal has \(\mu_K(\mathcal O)=1\). We extend the function by zero at the zero ideal, which never enters the column sums.

This is an ideal function, not the ordinary integer Möbius function evaluated at the norm. Lean counts prime-ideal factors with normalizedFactors, after testing squarefreeness.

¶source
noncomputable def mobiusK (n : Ideal 𝒪) : ℤ := by
  classical
  exact if n = ⊥ then 0 else
    if Squarefree n then (-1) ^ (normalizedFactors n).card else 0

5 · Ideals, primary generators, and rows

In the original family, \(\mathfrak n\) runs over nonzero integral ideals coprime to \((6)\). This matches the reference paper with its auxiliary Hecke character omitted and its excluded set chosen to be the primes above \(2\) and \(3\).

When we need an element representing a column ideal, the paper uses its unique primary generator \(n\equiv1\pmod{3\mathcal O}\), so \(\mathfrak n=(n)\), \(\mu_K(n)\) means \(\mu_K((n))\), and \(\chi_n\) means \(\chi_{(n)}\). This counts each ideal once, not its six associates. The correspondence with primary generators is not yet formalized.

The row variable \(u\) runs over every element of \(\mathcal O\). There is no primary, squarefree, or coprimality restriction on rows in the definition of the mean square. Thus the full lattice is available for Poisson summation.

¶source
def Admissible (n : Ideal 𝒪) : Prop :=
  n ≠ ⊥ ∧ n ⊔ Ideal.span {(6 : 𝒪)} = ⊤

def Primary (n : 𝒪) : Prop := (3 : 𝒪) ∣ n - 1

6 · The sextic character χ

For a nonzero prime ideal \(\mathfrak p\nmid(6)\), put \(q=\mathrm N\mathfrak p\). If \(u\in\mathfrak p\), set \(\chi_{\mathfrak p}(u)=0\). Otherwise it is the unique \(\zeta\in\mu_6\) satisfying

\[\zeta\equiv u^{(q-1)/6}\pmod{\mathfrak p}.\]

Here \(\mu_6=\{(-\omega)^j:0\le j<6\}\). For \(\mathfrak n=\prod\mathfrak p^{e_{\mathfrak p}}\) prime to \((6)\), extend in the denominator:

\[\chi_{\mathfrak n}(u)=\left(\frac{u}{\mathfrak n}\right)_6=\prod_{\mathfrak p\mid\mathfrak n}\chi_{\mathfrak p}(u)^{e_{\mathfrak p}}.\]

In particular, it vanishes if \((u)+\mathfrak n\ne\mathcal O\); the unit ideal gives the empty product \(\chi_{\mathcal O}(u)=1\), even for \(u=0\). Nonadmissible denominators are assigned zero and excluded from our sums.

The Lean definition selects the root by a sum of six indicators. Proving that exactly one matches at a good prime, and deriving the character identities, are next arithmetic steps; these facts are not being assumed as axioms.

¶source
noncomputable def sixthRoot (j : Fin 6) : 𝒪 := (-omega) ^ (j : ℕ)

noncomputable def primeSextic (p : Ideal 𝒪) (u : 𝒪) : ℂ := by
  classical
  exact if u ∈ p then 0 else
    ∑ j : Fin 6,
      if Ideal.Quotient.mk p (sixthRoot j) =
          Ideal.Quotient.mk p u ^ ((Ideal.absNorm p - 1) / 6)
      then toComplex (sixthRoot j) else 0

noncomputable def chi (n : Ideal 𝒪) (u : 𝒪) : ℂ := by
  classical
  exact if Admissible n then
    ((normalizedFactors n).map (fun p ↦ primeSextic p u)).prod
  else 0

7 · The Möbius partial sums Mᵤ(N)

Fix a smooth complex weight \(W\) supported on \([1/2,1]\). For \(u\in\mathcal O\) and positive \(N\), define

\[M_u(N)=\sum_{\substack{0\ne\mathfrak n\subseteq\mathcal O\\(\mathfrak n,(6))=1}}\mu_K(\mathfrak n)\chi_{\mathfrak n}(u)W\!\left(\frac{\mathrm N\mathfrak n}{N}\right).\]

This is a smooth partial sum of the ideal Möbius function. Only \(N/2\le\mathrm N\mathfrak n\le N\) contributes. For \(u=1\), the character is one and we recover the untwisted sum over the same admissible ideals.

idealBall N contains exactly the admissible ideals of norm at most \(N\). The arithmetic functions and norms are fixed definitions, not arguments to M. We suppress the fixed weight \(W\) in mathematical notation.

¶source
noncomputable def idealBall (N : ℕ) : Finset (Ideal 𝒪) := by
  classical
  exact (Ring.HasFiniteQuotients.finite_absNorm_le (S := 𝒪) N).toFinset.filter Admissible

noncomputable def M (W : SmoothDyadicWeight ℂ) (u : 𝒪) (N : ℕ) : ℂ :=
  ∑ n ∈ idealBall N,
    (mobiusK n : ℂ) * chi n u * W ((Ideal.absNorm n : ℝ) / (N : ℝ))

8 · The mean square and the full lattice

With a nonnegative smooth row weight \(V\) supported on \([1/2,1]\), set

\[S(N,H)=\sum_{u\in\mathcal O}V\!\left(\frac{\mathrm N(u)}H\right)|M_u(N)|^2.\]

This sum is over elements, including all associates. For positive \(H\), compact support restricts the contributing rows to \(H/2\le\mathrm N(u)\le H\). The zero row contributes zero because \(V(0)=0\).

Lean defines the finite sum first. Finiteness of the actual lattice norm ball is proved in IdealArithmetic.lean, and S_eq_tsum gives the sum over the whole lattice needed for Poisson.

Opening the square can introduce a factor \(\mathbf1_{(u,\mathfrak g)=1}\), where \(\mathfrak g\) is the common divisor of the column ideals. The reference paper handles this indicator by inclusion–exclusion, then applies Poisson on lattice residue classes. That step remains to be developed here.

¶source
noncomputable def S (W : SmoothDyadicWeight ℂ) (V : SmoothDyadicCutoff)
    (N H : ℕ) : ℝ :=
  ∑ u ∈ rowBall H, V ((elementNorm u : ℝ) / (H : ℝ)) * ‖M W u N‖ ^ 2
Whole-lattice identity and proof
theorem S_eq_tsum (W : SmoothDyadicWeight ℂ) (V : SmoothDyadicCutoff)
    (N H : ℕ) : S W V N H =
      ∑' u : 𝒪, V ((elementNorm u : ℝ) / (H : ℝ)) * ‖M W u N‖ ^ 2 := by
  classical
  unfold S
  rw [tsum_eq_sum (s := rowBall H)]
  intro u hu
  have hnorm : H < elementNorm u :=
    Nat.lt_of_not_ge (fun hle ↦ hu (mem_rowBall.mpr hle))
  by_cases hH : H = 0
  · have hV : V 0 = 0 := V.toSmoothDyadicWeight.eq_zero_of_lt_half (by norm_num)
    simp [hH, hV]
  · have hHpos : (0 : ℝ) < H := by exact_mod_cast Nat.pos_of_ne_zero hH
    have hratio : (1 : ℝ) < (elementNorm u : ℝ) / (H : ℝ) := by
      rw [lt_div_iff₀ hHpos]
      have hnorm' : (H : ℝ) < elementNorm u := by exact_mod_cast hnorm
      simpa using hnorm'
    rw [V.toSmoothDyadicWeight.eq_zero_of_one_lt hratio, zero_mul]

For the untwisted ideal series, the local convention is

\[\sum_{(\mathfrak n,(6))=1}\frac{\mu_K(\mathfrak n)}{(\mathrm N\mathfrak n)^s}=\frac{1}{\zeta_K(s)(1-4^{-s})(1-3^{-s})},\qquad\operatorname{Re}(s)>1.\]

The prime above 2 has norm 4; the prime above 3 has norm 3. The omitted factors are nonzero in \(\operatorname{Re}(s)>0\). The corresponding analytic argument has not yet been formalized.
